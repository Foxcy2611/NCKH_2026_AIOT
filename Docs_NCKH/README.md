# Docs_NCKH

Nơi chứa các tài liệu chính thức của đề tài: định nghĩa sản phẩm/kiến trúc đã chốt và kế hoạch triển khai.

## Nội dung

```text
Docs_NCKH/
├── README.md
├── NCKH_SPEC_MERGED.md
└── NCKH_PHAN_CONG_CONG_VIEC.md
```

- **`NCKH_SPEC_MERGED.md`** — Product Definition + System Architecture đã gộp: sản phẩm là gì, kiến trúc 2 node ra sao, AI model, audio pipeline, state machine, data model, ESP-NOW, Gateway, network, UI, power, các tham số chưa khóa, roadmap kỹ thuật.
- **`NCKH_PHAN_CONG_CONG_VIEC.md`** — Kế hoạch triển khai: ai làm gì trong 5 thành viên, thứ tự làm, output bắt buộc từng bước.

## Cách dùng

Đây là tài liệu **đã chốt/tham chiếu**, không phải nơi ghi tư duy đang làm — phần đó nằm ở `Docs_Member/`. Khi triển khai phát sinh thay đổi so với spec ở đây, cập nhật lại trực tiếp vào `NCKH_SPEC_MERGED.md` (không để hai nguồn lệch nhau).
