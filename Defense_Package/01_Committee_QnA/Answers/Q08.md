# Q08 — Kiến trúc DS-CNN V1 cụ thể gồm những layer nào? Tensor thay đổi kích thước ra sao qua từng khối?

## Trả lời vấn đáp

**Trả lời vấn đáp:** Kiến trúc **V1 DS-CNN** có đầu vào `[40,129,1]`, gồm ba khối **SeparableConv2D 3×3 → ReLU → Batch Normalization → MaxPool2D 2×2**. Số filter lần lượt **16, 32, 64**.

| Tầng | Kích thước đầu ra |
|---|---|
| Input | `40×129×1` |
| Block 1 | `20×64×16` |
| Block 2 | `10×32×32` |
| Block 3 | `5×16×64` |
| Flatten | `5×16×64 = 5120` |
| Dense + ReLU | `64` |
| Dropout | `0,30` (chỉ trong huấn luyện) |
| Dense(1) + Sigmoid | `1` |

Toàn mạng có **331.386 tham số** theo cấu hình báo cáo. Đầu ra Sigmoid ứng với **`p_non_asthma`** khi gán nhãn `0=Asthma`, `1=Non-Asthma`.

**Minh chứng nên chèn:** `model.summary()` hoặc sơ đồ layer.
