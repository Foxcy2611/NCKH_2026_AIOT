# Q50 — Dashboard kết nối MQTT Broker, Subscribe Topic, nhận JSON và cập nhật các thông số AI, SpO₂, HR, môi trường và GPS ra sao?

## Trả lời vấn đáp

**Trả lời vấn đáp:** Dashboard thiết lập kết nối đến **MQTT Broker**, **subscribe** các topic mà Gateway publish. Khi có message, lớp xử lý đọc payload **JSON**, kiểm tra cấu trúc/trường hợp lệ rồi cập nhật model/state nội bộ. Các trang QML hiển thị theo state mới: **nhãn/score AI, `vitals_valid`/HR/SpO₂, nhiệt độ–độ ẩm–áp suất, GPS và trạng thái Gateway/uplink**.

Mỗi event cần có **ID/sequence hoặc session ID** để giao diện phân biệt phiên mới với lần gửi lại. Dữ liệu không hợp lệ nên thành **“chưa có dữ liệu”** thay vì `0` thật. **Tên topic, định dạng JSON đầy đủ, cơ chế callback/signal và QoS** cần trích từ `Dashboard_Qt6`/config MQTT; không gán một topic tự nghĩ ra khi vấn đáp.

**Minh chứng nên chèn:** Một JSON thực tế + mũi tên map trường JSON lên từng widget.
