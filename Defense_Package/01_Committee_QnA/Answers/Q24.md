# Q24 — DSP trên ESP32-S3 được triển khai như thế nào để tạo được Log-Mel giống pipeline huấn luyện trên Python?

## Trả lời vấn đáp

**Trả lời vấn đáp:** DSP trên ESP32-S3 phải thực hiện **cùng hợp đồng frontend C4** như Python: mono/PCM16 **16 kHz**, **5 giây**, chuẩn hóa biên độ, **Butterworth bậc 5 100–2000 Hz**, **không pre-emphasis**, STFT **2048/Hann/hop625**, **40 Mel 100–2000 Hz**, log/dB `top_db=80`, sau đó **Min–Max theo Training** và lượng tử INT8.

Điểm quan trọng không phải code Python và C++ giống cú pháp, mà là **cùng thuật toán, hệ số lọc, quy tắc padding, cửa sổ Hann, Mel scale, chuẩn hóa và quantization**. Có thể kiểm tra trên **cùng PCM16**, so ma trận Log-Mel, tensor INT8 và đầu ra model, rồi kiểm tra lại bằng mic thật. **Không dùng frontend F0 64 Mel/pre-emphasis 0,97 để tạo đầu vào cho C4.**

**Minh chứng nên chèn:** Sai lệch các tensor Python/C++ từ một PCM16 cố định.
