# Q33 — Các TaskEspNow, TaskSensor, TaskConnManager, TaskSms, TaskMqttPublisher và TaskDisplayTFT được tổ chức và trao đổi dữ liệu như thế nào?

## Trả lời vấn đáp

**Trả lời vấn đáp:** **`TaskEspNow`** lấy gói từ Queue, kiểm tra tính hợp lệ, giải mã và gửi phản hồi bảo mật. **`TaskSensor`** duy trì cập nhật nhiệt độ/độ ẩm/áp suất và dữ liệu GPS vào snapshot. **`TaskConnManager`** theo dõi uplink Wi-Fi, điều khiển fallback LTE; **`TaskSms`** sử dụng A7680C để gửi thông báo; **`TaskMqttPublisher`** tạo JSON/CompleteRecord và xuất bản lên Broker; **`TaskDisplayTFT`** cập nhật nội dung tại Gateway.

Thông thường đường điều phối là **ESP-NOW event → latest Patient Event → ghép EnvironmentSnapshot → MQTT/TFT/SMS theo chính sách**. Truyền thông giữa task nên đi qua Queue hoặc trạng thái được đồng bộ, tránh mỗi task tự sửa packet gốc. **Tên Queue/Mutex và core pinning cụ thể** cần trích code nếu được hỏi sâu.

**Minh chứng nên chèn:** Sơ đồ tương tác 6 Task và vòng đời một event.
