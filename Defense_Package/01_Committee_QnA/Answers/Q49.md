# Q49 — Dashboard được xây dựng bằng Qt6/QML như thế nào? Vì sao chọn Qt6/QML thay vì Web Dashboard dùng React hoặc một framework khác?

## Trả lời vấn đáp

**Trả lời vấn đáp:** Dashboard là ứng dụng desktop **Qt6/QML**: tầng Qt/C++ hoặc Python binding (tùy source thực tế) đảm nhiệm **kết nối MQTT, parse dữ liệu và cập nhật state**, còn **QML** tổ chức các trang giao diện, bindings và thành phần hiển thị. Dashboard **không chạy model AI**; nó hiển thị dữ liệu do Gateway đã chuyển tiếp.

Nhóm chọn Qt6/QML vì cần một giao diện desktop phản hồi theo sự kiện, dễ làm trang điều khiển/hiển thị trạng thái và không bắt buộc triển khai web server riêng. React/web cũng khả thi nhưng cần hạ tầng giao diện web phù hợp. **Ngôn ngữ của backend UI, tên class MQTT và kiến trúc threading** chưa được mô tả chi tiết trong bản báo cáo nên phải xem `Final_Project_NCKH/Dashboard_Qt6/` nếu hội đồng hỏi tới mã nguồn.
