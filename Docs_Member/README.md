# Docs_Member

Nơi mỗi thành viên trình bày ý tưởng và cách mình triển khai phần việc của mình — code, state, layout, thiết kế, hay bất kỳ tư duy kỹ thuật nào trong lúc làm.

## Cách dùng

- Mỗi người tạo 1 file hoặc 1 folder riêng dưới đây, đặt tên theo mình (vd `M1_AI_Firmware.md`, hoặc folder `M1_AI_Firmware/` nếu nội dung dài).
- Viết tự do: sơ đồ state đang nghĩ, cấu trúc code, cách bạn triển khai một phần cụ thể, vì sao chọn cách này — miễn người khác đọc vào hiểu được bạn đang làm gì và tại sao.
- Cập nhật khi ý tưởng/triển khai thay đổi, không cần chờ xong mới viết.

## Ví dụ cấu trúc

\`\`\`text
Docs_Member/
├── README.md
├── M1_AI_Firmware.md
├── M2_OLED_UX.md
├── M3_Hardware.md
├── M4_Gateway_Firmware.md
└── M5_Network_Backend.md
\`\`\`

Nếu nội dung của ai đó phát sinh nhiều phần (vd nhiều sơ đồ, nhiều lần đổi hướng), chuyển từ 1 file sang 1 folder riêng cho người đó là được, không bắt buộc theo khuôn cố định.
